# SEO deployment checklist

1. Deploy this folder to the production Vercel project.
2. Make sure the production URL is https://geh-lab.vercel.app/ or replace that domain in the SEO tags if you use a custom domain.
3. In Google Search Console, add the production URL-prefix property and verify ownership.
4. Submit https://geh-lab.vercel.app/sitemap.xml in Search Console.
5. Request indexing for the homepage and the main public pages.
6. Do not submit preview deployment URLs.
